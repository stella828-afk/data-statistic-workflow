抖音周赛小程序

一 怎么运行
1. 双击同一文件夹里的“双击运行.bat”。
2. 窗口会打印每位 BD 的抖音业绩。
3. 打开“周赛_抖音结果.xlsx”，查看“周赛”工作表。
4. 每次运行会更新这个结果文件。如果它正在 Excel 中打开，请先关闭。

启动文件使用这台电脑已有的 Codex Python 环境，已包含 openpyxl。
不需要 API Key，不联网，也不会调用大模型。

二 输入和输出
输入文件：D:\【个人工作】\mamiya实习\A#周业绩播报\播报（周）7-10.xlsx
输入工作表：抖音订单
输出文件：程序旁边的“周赛_抖音结果.xlsx”
输出工作表：周赛，只有 BD 和抖音两列。

程序不改动原始文件，也不把结果写回原文件。
输出采用原“周赛”上方计算区 E6:F12 的人员顺序。
原表下方 E18:F24 的顺序不同，程序不重做跨平台的周总业绩排名。

三 计算规则
按“归属达人运营”（原表 AJ 列）匹配姓名，累加“计佣金额”（原表 L 列）。
例如：召召 = 田明召名下所有订单的计佣金额之和。
程序按表头查找列，即使这两列的位置改变，也可以继续使用。

这次直接复现原来的 SUMIF：
不额外筛选日期，不筛订单状态，不去重，不乘商品数量，不再扣一次退款。
金额列中的空白和文本不累加，与原 SUMIF 的行为一致。
名单外的归属不并入任何一位 BD；不会自动把“无归属”分给别人。
金额先按原始数值求和，再保留两位小数输出。

前一份玩具案例说明里的 PAID 筛选、去重等练习规则，不用于这个程序。

四 怎样读代码
用文本编辑器打开 douyin_weekly.py，从上往下看：
SOURCE_FILE：输入文件在哪里。
OUTPUT_FILE：结果文件保存在哪里。
BD_NAMES：报表昵称与订单姓名的对应关系。
calculate_totals：读取表格并累加金额。
save_results：把结果保存成新的 Excel。
main：把读取、计算、保存三个步骤连接起来。

五 Prompt 是做什么的
PROMPT.md 是让 AI 生成、解释或修改这个程序的提示词。
运行时由 Python 算数，不需要把 Prompt 再发送给大模型。
这是整个 AI 工作流里的“数据处理与计算”这一步。

六 如果换电脑
安装 Python 3.10 或更高版本，在本文件夹打开终端，运行：
python -m pip install -r requirements.txt
python douyin_weekly.py

“双击运行.bat”适配的是当前电脑；换电脑可使用上述命令。
换一份同格式数据时，修改代码开头的 SOURCE_FILE。
新增或更换参与榜单的人员时，修改 BD_NAMES。
